Get connected

  1. Download the ZIP and extract all files.
  2. Open sm-host.exe from the extracted folder.
  3. Follow the setup prompts and use the pairing code from your Stats Magic website.

This release is unsigned, so Windows may show a SmartScreen warning. Linux downloads are not available yet.

Verify your download

In PowerShell, run:

Get-FileHash .\sm-host-windows-amd64.zip -Algorithm SHA256

For v1.10.6, the result should be:
