Get connected

  1. Download the ZIP (Windows) or TAR.GZ (Linux) and extract all files.
  2. Open sm-host.exe from the extracted folder. On Linux, run ./sm-host from it.
  3. Follow the setup prompts and use the pairing code from your Stats Magic website.

The Windows build is unsigned, so Windows may show a SmartScreen warning. On Linux, SteamCMD needs 32-bit libraries: sudo dpkg --add-architecture i386 && sudo apt update && sudo apt install -y lib32gcc-s1

Verify your download

In PowerShell, run:

Get-FileHash .\sm-host-windows-amd64.zip -Algorithm SHA256

On Linux, run sha256sum -c SHA256SUMS --ignore-missing next to the download.

Compare the result with the release’s SHA256SUMS file.
