Get connected
  1. Download the ZIP (Windows) or TAR.GZ (Linux) and extract all files, then open sm-host.exe from the extracted folder. On Linux, run ./sm-host from it.
  2. On Windows, run the Setup.exe you downloaded. On Linux, extract the TAR.GZ and run ./sm-host from its folder.
  3. Follow the setup prompts and use the pairing code from your Stats Magic website.

Setup adds the Windows Firewall rules your servers need, so Windows does not ask about them later. Already on 1.13? Setup keeps your pairing, servers and game files, and starts servers that were running.

The Windows build is unsigned, so Windows may show a SmartScreen warning.

On Linux, SteamCMD needs 32-bit libraries: sudo dpkg --add-architecture i386 && sudo apt update && sudo apt install -y lib32gcc-s1

Plugins

Stats Magic Host installs these server plugins and keeps them up to date from a signed list, plugins/catalog.json. To install one by hand, use the same release and check its SHA-256.

Verify your download

In PowerShell, run:

Get-FileHash .\StatsMagicHost-Setup.exe -Algorithm SHA256

On Linux, run sha256sum -c SHA256SUMS --ignore-missing next to the download.

Compare the result with the release’s SHA256SUMS file.
